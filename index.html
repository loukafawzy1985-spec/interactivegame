للمعلم: لربط النتيجة بـ Google Sheets:

  1. افتح Google Sheets وقم بإنشاء ملف جديد.
  2. اذهب إلى الاضافات (Extensions) -> برمجة تطبيقات جوجل (Apps Script).
  3. انسخ الكود التالي والصقه هناك:
    function doPost(e) {
      var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
      var data = JSON.parse(e.postData.contents);
      sheet.appendRow([new Date(), data.name, data.className, data.score]);
      return ContentService.createTextOutput("Success");
    }
  4. اضغط على "نشر" (Deploy) -> "نشر جديد" (New deployment).
  5. اختر النوع "تطبيق ويب" (Web app)، الصلاحية "أي شخص" (Anyone).
  6. انسخ رابط الـ Webhook وضعه في متغير GOOGLE_SHEETS_WEBHOOK_URL في كود الـ JavaScript أسفل هذا الملف.
